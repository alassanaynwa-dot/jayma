Codes d'erreur AfricasTalking fréquents

  • InvalidSenderId — le Sender ID configuré n'est pas validé pour ce pays. Solution : vider AT_SENDER_ID en attendant que JAPPESI soit validé par AT.
  • InsufficientBalance — pas assez de crédit sur le wallet AT. Recharger via Billing → Top Up.
  • InvalidPhoneNumber — numéro mal formé après normalisation. Vérifier que le numéro est bien sénégalais (préfixe 70/75/76/77/78).
  • DeliveryFailure (en sandbox) — normal, le sandbox ne livre pas aux vrais numéros. Utiliser le simulateur AT pour vérifier la livraison.
